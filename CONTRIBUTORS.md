# Contributors

PairFree can only learn a model from the people who own it. Every device report or recording below added or
confirmed something for everyone who has the same earbuds, and the earbuds in the list are the ones PairFree
could check against real hardware. Thank you.

Names are the GitHub accounts the readings were posted from, with the issue each came from. If you would rather
be listed differently, or not at all, say so in an issue and it will be changed.

Want to be on this list? One report from your model helps: see [Help add your model](README.md#help-add-your-model).
