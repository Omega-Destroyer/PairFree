---- Reading ----

Observed: every reply's command is the request's plus 0100. The EQ write 0E01 is answered
by 0F81, the request plus 0180. Nothing on feature 05 changed after either EQ write.

Interpretation (no public spec; Qualcomm publishes GAIA v3 only under NDA): vendor 001D is
Qualcomm GAIA v3, whose command number is a 7-bit feature, a 2-bit packet type
(0 command, 1 notification, 2 response, 3 error) and a 7-bit command. Then:
- 00 00 is core "API version": 3.1. 00 01 is core "supported features": no more to come,
  then (feature, version) pairs 0D/1, 0C/1, 09/1, 05/1, 08/7, 01/3, 06/2, 07/1, 00/5.
- 0F81 01 is an error reply to feature 07 command 01, though the H3 still applies the EQ.
- Feature 05 is Qualcomm's music processing (EQ): 8 sets (00 01 02 03 06 08 09 3F, 3F being
  the user set), set 00 selected, a 5-band user set with every gain 0. Each band reads as
  2 bytes frequency, 2 bytes Q x 4096 (0B33 = 0.7), 1 byte filter type (0D), 2 bytes gain.
- SoundPEATS' 10-band EQ does not go through this feature, so it cannot be read here.
