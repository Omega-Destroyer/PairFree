PairFree is a free, open-source Android and Windows app that controls Jabra's Elite and Evolve2 earbuds and headphones that speak Jabra's own protocol without Sound+: no account, no internet access.

PairFree does not need Jabra Sound+ to run, but only one app can hold the control connection to the earbuds at a time, so close Jabra Sound+ first.

## What you can control

Each model shows only the settings it has:

- Battery for each earbud and the case.
- Noise control (off, noise cancelling, HearThrough) with its levels, and the modes the button cycles through.
- The equalizer with Sound+'s presets, the button functions, sidetone and the voice prompt language.

## On Windows too

Almost none of these brands makes a Windows app, so on a PC their earbuds are plain Bluetooth audio. PairFree for Windows is one small portable program (no installer) with the same settings as the Android app, in a window made for a mouse and with a tray icon for the battery and quick switches. It needs Windows 10 (version 1809) or 11, 64-bit, with the earbuds paired in Windows' Bluetooth settings. Jabra is covered.

## Jabra models

PairFree knows 34 Jabra models. Models that have been tried on real earbuds: Jabra Elite Active 75t.

Jabra support is read from Jabra Sound+ 5.22.0. It has not been tried with PairFree on any product yet.

If your model is not marked as tried, a device report from you adds it: see [how to help](https://github.com/Omega-Destroyer/PairFree#help-add-your-model).

## Why use PairFree

- **No account and no internet.** The app has no internet permission, so it cannot go online.
- **One app for several brands.** The same screens for every brand, instead of one app per pair of earbuds.
- **Open source.** GPL-3.0; the protocol is documented in the repository with tests, so anyone can check what the app sends to the earbuds.
- **Small and quick:** about 6 MB on Android and 16 MB on Windows, and reproducible: the published APK can be rebuilt from the source.
- **On Windows as well as Android,** where most of these brands have no app at all.

## Get PairFree

On Android, PairFree is on [F-Droid](https://f-droid.org/packages/io.github.omegadestroyer.pairfree/) and on the [GitHub releases page](https://github.com/Omega-Destroyer/PairFree/releases/latest); it needs Android 12 or later. On Windows 10 or 11, download `PairFree.exe` from the same releases page and run it.
