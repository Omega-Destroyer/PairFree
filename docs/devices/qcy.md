# QCY

PairFree is growing into one app for earbuds of several brands, with the same screens for each.
QCY support is new and has not been tried with PairFree on any earbuds yet: nobody on the project
owns a pair, so every model relies on reports from people who do.

PairFree lists QCY earbuds and headphones among your paired devices by their name. QCY's earbuds take
their settings over Bluetooth LE, and each pair advertises which model it is, so when you open a pair
PairFree looks for it nearby. Android asks you once to let PairFree find nearby devices; PairFree tells
Android it never uses that for your location, and the search stops as soon as the earbuds are found.

QCY builds its earbuds on chips from several makers. About half use QCY's own protocol, which PairFree
speaks. The other half use JieLi's protocol, which PairFree is still adding: for those PairFree says so
instead of trying.

What it shows, where the model has it:
- **Home:** the battery (each earbud and the case, or one for headphones), noise control (off, noise
  cancelling, transparency), the noise cancelling scene (adaptive, indoor, commuting, noisy or wind)
  and its strength, and the transparency level.
- **Sound:** the balance between the earbuds, spatial audio, dynamic EQ and adaptive volume.
- **Controls:** what a tap, double tap, triple tap and hold do on each earbud.
- **Device:** game mode, in-ear detection, LDAC, two devices at once, sleep mode (touch controls off),
  wind noise detection and the status light.

Not yet: the equalizer (QCY's app takes each model's presets from QCY's servers, which PairFree does not
contact), the ear tip fit test, and the models on JieLi's protocol.

QCY support is written from QCY's own app (QCY 4.0.7), read for its messages, and checked against
[OpenQCY-Desktop](https://github.com/GiorgioRafael/OpenQCY-Desktop) by GiorgioRafael (MIT), which was
tried on a MeloBuds N70. The model list and what each model offers come from QCY's product list as
[Quicky](https://github.com/hui1601/Quicky) by hui1601 recorded it. None of QCY's code is in PairFree.
`docs/qcy/PROTOCOL.md` describes the protocol.

## Help wanted

A device report from any QCY model helps:
1. Connect the earbuds in PairFree.
2. Tap **Copy device report** on the Device tab.
3. Paste it into a new issue.

It lists the model and firmware and the last value of each setting PairFree reads, with no serial
number, address or name. Say which settings worked and which did nothing. On models marked "Not yet",
the report is empty for now; say which model you have, so it can go first when JieLi's protocol comes.
